## New

- **Repo tabs.** Open any repo in its own tab from a repo tile, a link, the command palette or the **+** button. Drag tabs to reorder them, close them with **×** or a middle-click, cycle with `Ctrl+Tab` / `Ctrl+Shift+Tab`, and find them again after a restart. Each tab remembers which section you were on.
- **Repo picker.** The **+** button lists the repos you watch and every repo on your account (up to 500, most recently pushed first), searchable as you type. It still opens any `owner/name` or GitHub URL.
- **GitHub tools in every repo tab**:
  - **Issues**: browse, read, comment, close or reopen, and create issues with labels.
  - **Branches**: see how far each is ahead of or behind the default branch, create and delete branches, and start a pull request.
  - **Commits** for any branch, with a copy-SHA button.
  - **Releases**: read notes and download assets, and publish a release or draft with generated notes.
  - **New pull request** and **New issue** buttons in every repo header. Issue links now open in the app too.
- **Local git tools** in the new **Working copy** section. Link an existing clone or clone the repo, then:
  - see changes with diffs; stage, unstage or discard; and commit (`Ctrl+Enter`)
  - stash and pop
  - browse history, and switch or create local branches
  - fetch, pull (fast-forward only) and push, including publishing new branches
  - open the folder in your editor (set it in Settings), a terminal or the file manager

  Git only runs in folders you've picked yourself, and never prompts for credentials.
