The first public release, published as **Flightdeck** (renamed Pushback in 0.3.0). A desktop dashboard for GitHub Actions and pull requests across all the repos you care about.

## New

- **Customisable dashboard.** Drag and resize widgets on a grid: repo summary, workflow runs, pull requests, run a workflow, activity feed, a cross-repo "My work" inbox and CI insights. Add any widget more than once, give each its own title, repos and options, and filter them live.
- **Run workflows** with their `workflow_dispatch` inputs (choices, booleans and text).
- **Run details**: jobs and steps with live durations, and the failed job's log opened at the first error. Cancel, re-run failed jobs or re-run everything.
- **Pull request actions**: approve, and merge (squash, merge or rebase) behind a confirmation.
- **Desktop notifications** when runs finish or fail, PRs are opened, merged or ready for review, reviews are requested, or checks fail.
- **Command palette** (`Ctrl/⌘+K`) over PRs, runs, workflows, repos and commands, plus shortcuts for refresh (`Ctrl/⌘+R`), edit layout (`E`) and settings (`Ctrl/⌘+,`).
- **Themes**: dark, light or follow the OS. Presets include GitHub Dark/Light (default), Terminal, Amber CRT, Atom One, Dracula, Synthwave '84, Monokai, Nord, Tokyo Night, Catppuccin, Gruvbox, Solarized, Rosé Pine Dawn and Paper. Override any colour, pick any installed font and text size, and turn on glow or CRT effects for the retro themes.
- **Sign in** with the GitHub CLI or a personal access token (stored encrypted). Polling stays light on the rate limit thanks to ETag caching.
- **Auto-updates** from GitHub Releases: installs in the background on Windows and AppImage, and shows a "new version" link on macOS and .deb. You can switch it off in Settings → Advanced.
- Installers for Windows (NSIS), macOS (arm64 and Intel DMGs) and Linux (AppImage and .deb).
