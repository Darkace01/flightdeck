## Flightdeck is now Pushback

An unrelated app called FlightDeck already exists, so the app has a new name. Your settings, dashboards, history and sign-in carry over automatically the first time you open Pushback.

## New

- **Pull requests open in the app.** Click a PR anywhere (widgets, inbox, activity, palette or a notification) to see its description, conversation, commits, checks and a diff of changed files. Approve, merge or comment from there, or use **Open in browser**.
- **Repos open in the app** with their README and that repo's PRs, runs, workflows and insights, plus a button to start or stop watching it. Views stack, so closing a PR you opened from a repo takes you back to the repo.
- **Multiple dashboards.** Create as many as you like, each with its own widgets and layout, from a template (Overview, CI monitor, Code review, Release manager, Focus or Blank) or as a copy of an existing one. Switch from the menu next to the logo, the command palette or `Ctrl/⌘+1…9`, and rename, reorder, duplicate or delete them in **Manage dashboards**. Your existing layout becomes a dashboard called Main.
- **Package managers**: install on macOS with `brew install --cask darkace01/tap/pushback`. A winget package (`Darkace01.Pushback`) has been submitted to the Windows Package Manager.
