## New

- **Find repos on this computer.** In **Settings → Repositories**, click **Find on this computer…** (or run *Find repos on this computer* from `Ctrl/⌘+K`). Pushback looks through your home folder for git repos with a GitHub remote (`origin` first) and lists every one it finds in about a second, including clones whose folder name differs from the repo. Pick the ones you want and click **Add**:
  - Each is linked as that repo's **Working copy**, so the git tools work straight away.
  - Tick **Also watch them on the dashboard** to add their runs, PRs and notifications too. Pushback warns you if that would mean watching enough repos to strain GitHub's rate limit.
  - If you've cloned a repo more than once, it uses the copy you've used most recently.
  - Keep your code somewhere else, like another drive? Use **Look in another folder…**.
- **Link new clones automatically.** Turn this on in the same dialog, and each time Pushback starts it links any new clones it finds. It never changes which repos you watch.
