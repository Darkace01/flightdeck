## New

- **Dashboard tabs.** Your dashboards now sit as tabs next to the logo, so switching is one click. The first five show as tabs (the one you're on always stays visible), and the **▾** menu holds the rest, plus **New dashboard…** and **Manage dashboards…**. Switching dashboards from anywhere (tabs, `Ctrl/⌘+1…9` or the command palette) also brings you back to the dashboard tab.
- **Choose your default editor or IDE.** **Settings → Advanced → Default editor / IDE** lists the editors installed on your computer: VS Code and VS Code Insiders, Cursor, Windsurf, Zed, Sublime Text, JetBrains IDEs (IntelliJ IDEA, WebStorm, Rider, PyCharm, GoLand), Fleet and Visual Studio. You can also enter any other command. The Working copy's **Open in** button shows the editor's name. If you never changed the setting and VS Code isn't installed, Pushback uses the first editor it finds.
- **Skeleton loading.** Dashboards, lists, repo sections, READMEs, and PR and issue views show placeholders shaped like their content while they load, instead of "Loading…". The animation stops if your system is set to reduce motion.

## Improved

- **Repo picker.** The **+** button at the end of the tab bar opens a proper dropdown, with the search box on top and your repos below. It no longer gets cut off or pushes your tabs out of view.
- **Startup.** While your data loads you see your dashboard's layout, instead of the sign-in screen flashing up first.

## Fixed

- Repo tabs restored at launch could fail with "Not signed in" and never load. They now wait for sign-in to finish.
- Updated a build-time dependency (minimatch) to address a security advisory. This doesn't affect the installed app.
