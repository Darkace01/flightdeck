## New

- **Everything opens as a page, with breadcrumbs.** Pull requests, issues and workflow runs now open as pages inside the dashboard or repo tab you clicked them from, not on top of it.
  - Breadcrumbs above the content show where you are and how many levels deep, for example *Main › owner/repo › #42 Fix login*.
  - Click any crumb to go back up to it, or press `Esc` (or **←**) to go back one level.
  - Inside a repo tab, the repo's sections stay on the left while you read.
- **Filters on every widget.** Click the funnel in any widget header to filter it by repo, plus that widget's own filters:
  - **Runs:** status, branch, workflow, trigger, who started it, latest only
  - **Pull requests:** status, branch, author, label, hide drafts
  - **Activity:** type, unread only
  - **Insights:** branch, workflow
  - **Deployments:** view, environment, outcome

  Branch, workflow, author and label suggest values from your data. Filters apply as you choose them and are saved with the widget; the funnel shows how many are set, and **Clear** resets them. Repo sections built from widgets have the same filter bar.
- **A walkthrough for new users.** The first time you open Pushback, a short tour points out the sidebar, dashboards, breadcrumbs, widget filters, layout editing, search, repo tabs and settings. Replay it any time with **Take the tour** in the command palette, or from **Settings → Advanced**.

## Improved

- **Vertical tabs are now the default.** Your tabs and watched repos sit in the sidebar on the left. Prefer them across the top? Choose **Across the top** in **Settings → Appearance → Tabs**.
- **Tested before every release.** Every release now has to pass about 150 automated tests on Windows, macOS and Linux before it's built:
  - unit tests of the app's logic
  - git tests against real repositories
  - end-to-end tests that click through the app

## Fixed

- **Searching commits by SHA** with text that isn't a SHA showed an error. It now shows no results.
