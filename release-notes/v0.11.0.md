## New

- **Switch between GitHub accounts.** You can now add more than one github.com login (Settings → Account → Accounts), next to your GitHub Enterprise Server accounts. A switcher in the top bar picks the active account, and the dashboard, inbox and polled repos follow it. Each repo stays with the account it was added under, so switching never mixes tokens. Search, Packages and the repo picker use the active account too.

- **Dashboard icons.** Every dashboard has an icon you can pick in Manage dashboards. The top-bar tabs show it, and when the bar gets crowded inactive tabs shrink to just their icon instead of a name cut off with an ellipsis.

## Improved

- **Far less rate limiting.** Identical requests made at the same moment now share one call. When GitHub's REST budget runs out, or GitHub asks Pushback to back off (`Retry-After`), requests stop until it is allowed again and cached data is shown meanwhile. As the budget runs low, polling slows down so what is left lasts until the reset. The request cache is also capped so it can't grow without limit.

## Fixed

- Pasting a github.com repository link now goes to the account chosen in the form when you have several github.com logins.
